# AgriPredict AI — aivancity 2026

Projet réalisé dans le cadre de la **Clinique IA d’aivancity**.

AgriPredict AI est une plateforme d’intelligence artificielle agricole multimodale combinant données satellitaires, météorologiques, pédologiques et historiques afin de :

- prédire les rendements agricoles ;
- recommander les cultures les plus adaptées ;
- anticiper la sévérité des sécheresses ;
- expliquer les prédictions et estimer leur incertitude ;
- proposer une démonstration complète via API et interface web.

## Architecture IA envisagée

- Random Forest, XGBoost et modèles linéaires comme baselines ;
- MLP, TabNet et FT-Transformer pour les données tabulaires ;
- LSTM, GRU, TCN et Transformer temporel pour les séries météorologiques et satellitaires ;
- fusion multimodale des données temporelles, géographiques et pédologiques ;
- stacking et ensemble learning ;
- SHAP, Integrated Gradients et conformal prediction ;
- MLflow, DVC, FastAPI, Docker, tests et GitHub Actions.
